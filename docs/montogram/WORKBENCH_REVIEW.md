# Дополнения после alpha.5: собственные инструменты

Это код следующей сборки, не содержимое уже опубликованной alpha.5.
M24/M32/M34/M46 используют только вручную введённый текст и существующие
проверки аккаунта, блокировки, pause/destroy и потери window focus. Нет чтения
буфера обмена, сообщений, файлов, сети или автоматической отправки.

| ID | Штатный аналог и отличие | Границы | Доказательство |
|---|---|---|---|
| M24 | SendMessagesHelper.java:10665 автоматически делит отправляемый текст. Здесь до отправки выбирается и просматривается отдельная часть для ручного копирования; отправки нет. | 8192 UTF-16 на вход, лимит частей от текущего Telegram maxMessageLength, максимум256 частей; surrogate/CRLF не разрезаются. Обычный текст без entities; не обещает границы всех grapheme clusters. | JVM round-trip и Unicode fixtures |
| M32 | SettingsChange сравнивает настройки; DiffUtils обновляет UI-списки. Отдельного действия для сравнения двух собственных текстов нет. | Два входа по8192 UTF-16; линейные common prefix/suffix по code points, один заменяемый участок, не минимальный edit script; вывод<=32768 UTF-16. | JVM реконструкция второго текста, emoji,1000 случайных пар |
| M34 | Browser/AndroidUtilities извлекают host для навигации. Здесь отдельный отчёт структуры без навигации и без значений query, userinfo или fragment. | Только HTTP(S), IDN→ASCII без DNS; до128 имён параметров, остальные считаются; неподходящие имена скрыты. Не оценка безопасности URL и не общее удаление всех возможных секретов из path. | JVM userinfo/query/fragment exclusion, IDN/IPv6/ports/limits |
| M46 | Штатные проверки username/ссылок не дают отчёт о смешении алфавитов в произвольном введённом тексте. | Конечные диапазоны Latin/Cyrillic/Greek, максимум128 находок, позиции в code points; advisory, не homoglyph/security verdict. | JVM смешанные слова, single-script, cap/omitted |
| M58 | SettingsActivity.getVersionName():951 показывает версию/ABI в footer, debug меню собирает логи. Новый отдельный копируемый структурированный отчёт содержит публичную версию, Android API, ABI, report schema без логов/аккаунта. | Версия<=80 безопасных символов, до16 ABI по32 символа. Не содержит путей, IDs аккаунта, токенов, значений пользовательских настроек. | JVM public-field allowlist; Android copy/UI ожидают CI/device |

Каждый валидный вход ограничен8192 UTF-16, следовательно не более24576 UTF-8
байт. Два входа сравнения — не более49152 байт вместе. Вывод ограничен32768
UTF-16 (не более98304 UTF-8 байт). Новых зависимостей нет.

Проверки: `python3 setup/test_montogram_workbench.py` —5090 checks PASS;
`workbench-resource-checks.json` — XML/уникальные(type,name,product)/RU+EN.
Это не доказательство aapt linking, полной сборки или Android runtime.
M57 не засчитывается до доказанного отличия от M06. Цвета/варианты отдельно
не добавляют функций. Следующая сборка — один общий CI после пакета изменений.
