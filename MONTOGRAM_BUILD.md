# Montogram build notes

See [BUILDING.md](BUILDING.md) for this repository’s root-level layout, pinned
toolchain, private local configuration, manual CI workflow and verification
limits. The original upstream README is preserved in
[docs/UPSTREAM_README.md](docs/UPSTREAM_README.md).

Application: `app.montogram.android`; independent Telegram fork, not an official
Telegram application. Default interface remains Telegram; optional Montogram
settings are opt-in. No language rewrite is attempted.
