# Изменения

## В работе — следующая alpha

- Новый красный знак M, баннер и оформление проекта.
- Отдельный creator action для профиля числового ID5672308380; не Telegram status.
- Последние изменения компонентов MD3 и управления движением переключателей.
- Локальные текстовые инструменты, поиск заметок и шаблонов.
- Исправление потери ввода заметки при ошибках Save/Delete.

Эти пункты находятся в исходниках с разными уровнями проверок. Новый APK не
собран; Android runtime и полный набор60+функций ещё не подтверждены.

## Историческая внутренняя alpha — build20048

APK была собрана, подписана и передана приватно. В неё не входят перечисленные
выше последние изменения. Это не новый GitHub release и не доказательство
паритета с другими Telegram-клиентами.

### Подготовлено в исходниках, ещё не в APK

- Новая красная M с переходом в радужные светящиеся частицы; баннер и social preview.
- Основная launcher-иконка и её превью; пять альтернативных иконок сохранены.
- Отдельный значок создателя по числовому Telegram ID с нижним native bulletin.
- Свежие изменения прошли выбранную SDK-компиляцию; полноценный новый APK и Android-проверка ожидаются.
