# Изменения

## 0.2.0-alpha.5 — build 20058 · 2026-10-30

[Скачать релиз](https://github.com/byteKayze/MontoGram/releases/tag/v0.2.0-alpha.5). Версия в APK:
`0.2.0-alpha.5-internal-unminified`; только arm64-v8a и x86_64.

- Красная M, новые launcher-иконки, баннер и оформление репозитория.
- Отдельный значок создателя Montogram для числового ID `5672308380` с нижним уведомлением.
- Последние изменения компонентов MD3 и движения переключателей; MD3 включается отдельно.
- Локальные текстовые инструменты, поиск заметок и быстрых ответов.
- Исправление потери ввода заметки при ошибках сохранения и удаления.
- Guava 33.7.2-android вместо уязвимой версии; строгая проверка Maven-артефактов сохранена.
- Сборка в GitHub Actions: отдельный Java-компилятор, затем каноническая нативная сборка и упаковка.

CI, локальная подпись постоянным ключом, SHA-256, package/version, ABI и
16-КБ ZIP/ELF-выравнивание проверены. Файлы релиза скачаны обратно и сверены
по хешам. Тег указывает на собранный commit `e8193b041494bc1dd060ff336e04c912d01600aa`.
Это не доказательство локальной воспроизводимости или полного аудита зависимостей.

Полные 60+ функций и полный MD3 ещё не закончены. Android runtime не проверялся.
Контексты подтверждений действий и локального хранения покрыты частично;
собственная конфигурация Google-проекта отсутствует. Эта alpha не является
заявлением о паритете с другими Telegram-клиентами.

## Историческая внутренняя alpha — build 20048

Предыдущая APK была собрана, подписана и передана отдельно. В ней отсутствовали
перечисленные выше новые брендовые материалы и последние правки. Её исходные
архивы не следует использовать как полные исходники APK build 20058.
