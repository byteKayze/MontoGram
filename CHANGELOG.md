# Изменения

## 0.2.0-alpha.7 — build20078

Три новые функции относительно alpha.6: opt-in Reader одного разрешённого обычного сообщения; Unicode simple-case поиск с prev/next и лимитами; временное копирование с opaque per-copy token и проверкой неизменённого содержимого перед best-effort очисткой. Создание копии требует foreground, cleanup собственной копии пытается работать и после потери фокуса/смены аккаунта. Неудачная замена сохраняет старый callback очистки. No services/listeners/worker threads. Android не даёт гарантий удаления истории буфера.

Reader выключен по умолчанию. Secret/TTL/protected/paid/group/spoiler/unknownpeer исключены. Текст/query не сохраняются; pause/focus/account notifications отзывают просмотр. Документация и проверки: [READER_REVIEW.md](docs/montogram/READER_REVIEW.md).

Всего39 реализаций скомпилировано в APK,5частично,21планируется. Это не Android-приёмка: DEVICE0. Полные60+/MD3, реальный clipboard/SAF/lifecycle и локальная воспроизводимость не подтверждены. Подпись/hash/source/24-file manifest и GitHub/Drive readback отмечаются отдельно.


## 0.2.0-alpha.6 — build20068

11 самостоятельных новых функций относительно alpha.5:

- Разбиение собственного plain text на части без разрыва суррогатных пар/CRLF; preview и явное копирование.
- Сравнение двух вручную введённых текстов по общим Unicode prefix/suffix.
- Разбор HTTP(S) без сети, с сокрытием query values/userinfo/fragment.
- Advisory смешанных Latin/Cyrillic/Greek алфавитов.
- Безопасный отчёт версии/ABI для поддержки.
- Локальные папки закладок с явным перемещением/расформированием.
- Экспорт собственных заметок через SAF с раскрытием полей и подтверждением после picker.
- Перенос/импорт шаблонов с preview, дедупликацией и атомарным merge по owner/revision/digest.
- Панель количества/serialized-model-bytes локальных записей.
- Экспорт собственных меток/refs закладок без message bodies.
- Выбор и атомарное удаление группы собственных заметок.

Raw buffers стираются при cancel/timeout даже при зависшем fake provider; существующий settings backup использует тот же единственный ограниченный worker. Точные18 изменённых app inputs закреплены manifest SHA; CI проверяет их перед сборкой и передачей APK. Есть целевые JVM/fake-PFD проверки и независимое ревью. Это не реальные Android SAF/lifecycle тесты.

Всего36 SOURCE-реализаций,5частичных,24планируемых. Полные60+/MD3 и Android runtime не завершены. Собственная Google-конфигурация отсутствует, unminified/universal64 ограничения сохранены.


## 0.2.0-alpha.5 — build 20058 · 2026-10-30

[Скачать релиз](https://github.com/byteKayze/MontoGram/releases/tag/v0.2.0-alpha.5). Версия в APK:
`0.2.0-alpha.5-internal-unminified`; только arm64-v8a и x86_64.

- Красная M, новые launcher-иконки, баннер и оформление репозитория.
- Отдельный значок создателя Montogram для числового ID `5672308380` с нижним уведомлением.
- Последние изменения компонентов MD3 и движения переключателей; MD3 включается отдельно.
- Локальные текстовые инструменты, поиск заметок и быстрых ответов.
- Исправление потери ввода заметки при ошибках сохранения и удаления.
- Guava 33.7.2-android вместо уязвимой версии; строгая проверка Maven-артефактов сохранена.
- Сборка в GitHub Actions: отдельный Java-компилятор, затем каноническая нативная сборка и упаковка.

CI, локальная подпись постоянным ключом, SHA-256, package/version, ABI и
16-КБ ZIP/ELF-выравнивание проверены. Файлы релиза скачаны обратно и сверены
по хешам. Тег указывает на собранный commit `e8193b041494bc1dd060ff336e04c912d01600aa`.
Это не доказательство локальной воспроизводимости или полного аудита зависимостей.

Полные 60+ функций и полный MD3 ещё не закончены. Android runtime не проверялся.
Контексты подтверждений действий и локального хранения покрыты частично;
собственная конфигурация Google-проекта отсутствует. Эта alpha не является
заявлением о паритете с другими Telegram-клиентами.
