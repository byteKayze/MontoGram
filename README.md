# Montogram

Независимый Android-клиент на открытой основе Telegram. Привычный интерфейс
по умолчанию, собственные инструменты и дополнительное оформление — по выбору.

**Доступна alpha.7 — build 20078.** [Скачать APK](https://github.com/byteKayze/MontoGram/releases/download/v0.2.0-alpha.7/Montogram-0.2.0-alpha.7-build20078-universal64.apk) · [Релиз и контрольные суммы](https://github.com/byteKayze/MontoGram/releases/tag/v0.2.0-alpha.7).
Добавлены3 функции относительно alpha.6: чтение выбранного сообщения, поиск в Reader и временная копия с проверкой владения буфером.
Это не официальный продукт Telegram.

## Как устроены настройки

Обычный Telegram остаётся исходным режимом. Дополнительные настройки находятся
в разделе Montogram. Material 3 и собственные изменения поведения включаются
явно. Изменения оформления не дают Telegram Premium или новых серверных прав.

Локальные заметки, закладки и шаблоны привязаны к аккаунту. По умолчанию они
живут в текущем процессе; постоянное шифрованное хранение выбирается отдельно.
Экспорт заметок/шаблонов передаёт открытый текст выбранному файловому провайдеру только после явного согласия. Размеры в панели — сериализованная модель, не RAM/диск. Папки используютMBK2, который старые версии не читают. Reader включается в Montogram → Chat tools → «Читать выбранный текст», затем открывается через меню обычного доступного сообщения. Он не работает с защищёнными/исчезающими/платными сообщениями, группами медиа и спойлерами. Текст очищается при уходе/потере фокуса; временная копия делает попытку очистки через минуту или при уходе, но Android и история буфера могут сохранить её. Подробности: [Reader review](docs/montogram/READER_REVIEW.md). Перед использованием alpha прочитайте ограничения конкретного релиза.

## Визуальный стиль

Красная M с чётким основанием и постепенным переходом вверх-вправо в радужные
светящиеся частицы. Баннер и основной знак подготовлены специально для проекта.
Изображённые частицы — статичная графика; приложение не запускает ради них
постоянную анимацию или фоновый сервис.
